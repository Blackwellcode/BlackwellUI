## Game data and game content (not bundled)

- **`SpellIcons.lua`** is generated by BlackwellUI's own build tool from the game client's data files (`DBFilesClient\Spell.dbc` and `SpellIcon.dbc`). The spell names and icon file names it lists are part of the World of Warcraft game data by Blizzard Entertainment, as shipped with Azeroth Survivors. BlackwellUI claims no rights in those names; the compilation, its format and the tool are BlackwellUI's own work.
- **`AbilityNames.lua`** is generated by BlackwellUI's own build tool from the language data built into the Azeroth Survivors client (`ability.<key>.name` in each of the game's 14 languages). The ability names are the game's; BlackwellUI uses them only to show spells in the player's language and to map them back to English for icon lookups. The rest of BlackwellUI's translations (`Locales/*.lua`) are BlackwellUI's own work.
- **`GameStrings.lua`** is generated the same way from the game's language data: the game's own wording of a few spell tooltip markers (for example "Talents: ", "Automatic", the cooldown and critical strike lines and the spell school names) in each of the game's 14 languages. BlackwellUI uses them only to read the game's tooltips in whatever language the game runs in.
- **Game textures and fonts** referenced at runtime (for example `Interface\Icons\*`, `Interface\TargetingFrame\UI-StatusBar`, `Fonts\FRIZQT__.TTF`) belong to the game client. They are not included in BlackwellUI.
